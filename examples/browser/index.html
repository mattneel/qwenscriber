Qwenscriber

Local-first Qwen3-ASR runtime. This page reports what the host supports, runs the core's self-test, preprocesses a tone with the real WASM module in a worker, and runs one WebGPU kernel (matmul_q4, fused dequantize + matmul over the packed weight layout) against the same CPU reference the GPU test harness uses. Transcription is not implemented in ABI v1, and the last section shows the typed error that says so rather than a fake transcript.
